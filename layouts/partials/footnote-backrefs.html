{{- /* Goldmark's footnote extension hard-codes the back-reference link text as the Unicode character U+21A9 (↩︎), which screen readers announce inconsistently ("leftwards arrow with hook" on some, nothing meaningful on others). Articles here can carry 30-50 footnotes, so dozens of identically-ambiguous links appear in sequence, violating WCAG 2.4.4 Link Purpose in Context. This Hugo version doesn't expose footnote render hooks or backlink config, so the fix post-processes the rendered content: give each backref an aria-label naming the footnote it returns to, and hide the decorative arrow glyph from assistive tech. Usage: {{ partial "footnote-backrefs.html" .Content }} */ -}} {{- $pattern := `(?s).*?` -}} {{- $replacement := `↩︎` -}} {{- replaceRE $pattern $replacement . | safeHTML -}}
