# Current Research in Digital History

This repository contains the website for [*Current Research in Digital History*](https://crdh.rrchnm.org/), a publication of the [Roy Rosenzweig Center for History and New Media](https://rrchnm.org) at George Mason University.

## Adding an essay

See [docs/adding-an-essay.md](docs/adding-an-essay.md) for the step-by-step checklist (folder naming, front matter, figures, DOI).

## Building the site

The site is built with [Hugo](https://gohugo.io/) (extended edition for the asset pipeline). Styles are generated by Tailwind CSS through PostCSS, so Hugo needs the Node dependencies installed before it can build.

Requirements:

- Hugo 0.161.1 (see the `Dockerfile`)
- Node.js and npm
- [just](https://github.com/casey/just), optional, for the shortcuts below.

Setup and preview:

```sh
npm ci                  # or: just setup
hugo server --buildDrafts --navigateToChanged   # or: just preview
```

The site is served at <http://localhost:1313/>.

Other commands:

| Task | just | Direct |
|---|---|---|
| Preview with drafts and live reload | `just preview` | `hugo server --buildDrafts --navigateToChanged` |
| Production build into `public/` | `just build` | `hugo --minify` |
| Build with the same flags as CI | `just build-ci` | `hugo --buildDrafts --buildFuture` |
| Remove build output and caches | `just clean` | `rm -rf public resources/_gen .hugo_build.lock` |

`npm run dev` and `npm run build` are aliases for the preview and production builds.

## Repository layout

| Path | Contents |
|---|---|
| `content/essays/` | One page bundle per essay: `index.md` plus its images. |
| `content/conference/`, `content/*.md` | Conference pages and the About and Submissions pages. |
| `layouts/` | Hugo templates, partials, and the `figure` and `plot` shortcodes. |
| `assets/` | Tailwind CSS and JavaScript sources processed by Hugo Pipes. |
| `static/` | Files copied to the site root unchanged. |
| `hugo.yaml`, `config/` | Site configuration, with per-environment overrides for the base URL. |
| `doi/` | Crossref deposit XML for registered DOIs. |
| `Dockerfile` | Production image: builds the site and serves `public/` with Caddy. |

`public/` and `resources/_gen/` are build output and are not committed.

## Deployment

Pushes to the `preview` and `main` branches run the GitHub Actions workflow in `.github/workflows/cicd.yml`, which uses the shared CHNM Hugo workflow to build the Docker image and deploy it. `preview` publishes to <https://dev.crdh.rrchnm.org> and `main` to <https://crdh.rrchnm.org>.

The deployed build runs `hugo --buildDrafts --buildFuture`, so draft and future-dated content is published. A weekday scheduled run rebuilds the site when an essay's publish or expiry date has passed.
